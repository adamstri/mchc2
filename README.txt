MCHC website starter

Files:
- index.html: bilingual Hebrew/English website
- logo.png: clinic logo

To preview: keep index.html and logo.png in the same folder, then open index.html in a browser.

Optional hero image:
Add a clinic photograph named clinic-hero.jpg to this folder. The homepage is styled to use it as the hero background. If the file is absent, a dark fallback background appears.

The contact section intentionally uses email/phone links instead of an active form. Do not collect national ID numbers or sensitive medical details through an unsecured static website. A secure backend would be needed for a real form.

Please verify clinic details and opening hours before publishing.
